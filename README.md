# Video Game Sales Analysis: Impact of 3rd Person Perspective

## Overview
This project analyzes whether third-person perspective in video games is associated with higher commercial success in the U.S. market. The analysis uses statistical inference and hypothesis testing on a dataset of video game sales.

## Business Question
Does game perspective (third-person vs. others) impact U.S. video game sales?

## Methodology
- Exploratory Data Analysis (EDA)
- Bootstrap resampling (1000 iterations)
- Confidence interval estimation
- Two-sample hypothesis testing

## Key Findings
- 90% confidence interval for proportion of third-person games: **73%–77%**
- No statistically significant difference in sales by game perspective (p-value = 1.0)
- Game perspective alone is not a strong predictor of commercial success
